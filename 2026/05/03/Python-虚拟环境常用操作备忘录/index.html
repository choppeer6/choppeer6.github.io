💡 4. 避坑小贴士 (Tips)

  1. 别把虚拟环境传到 Git 上！
    千万记得在你的 .gitignore 文件中加上一行 venv/ 或 .env/。虚拟环境文件夹里包含了大量的可执行文件和库，体积巨大，且只能在本地运行，传到代码仓库里毫无意义。
  2. VS Code 识别不到虚拟环境？
    按下 Ctrl + Shift + P (或 Cmd + Shift + P)，输入 Python: Select Interpreter，然后手动选择你刚才创建的 venv/Scripts/python.exe（Windows）或 venv/bin/python（Mac/Linux）即可。

结语：无论是极简的 venv 还是全能的 conda，养成“一个项目，一个环境”的好习惯，能帮你省去 80% 莫名其妙的报错排查时间。
