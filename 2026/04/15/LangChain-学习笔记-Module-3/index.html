交互流程

  1. 用户提供邮箱密码 → Agent 调用 authenticate → 状态更新为已认证
  2. Agent 自动 check_inbox → 读取邮件内容
  3. 用户要求回复 → Agent 起草邮件并调用 send_email
  4. HITL 中断 → 用户 approve/reject/edit → 邮件发送

案例要点

  1. 状态驱动：authenticated 状态控制整个 Agent 的行为
  2. 动态组合：工具 + 提示词 + 模型调用全部支持动态化
  3. 安全管控：敏感操作（发邮件）通过 HITL 增加人工审批
  4. 用户体验：认证后自动进入邮件处理流程，无需重复指令

总结

Module 3 涵盖了构建生产级 AI Agent 所需的高级能力：

主题 核心技能
消息管理 SummarizationMiddleware、自定义 before_agent 中间件、RemoveMessage
人在回路 HumanInTheLoopMiddleware、interrupt_on、Approve/Reject/Edit
动态模型 wrap_model_call + request.override(model=...)
动态提示词 dynamic_prompt + 运行时上下文
动态工具 wrap_model_call + request.override(tools=...)
综合应用 邮件助手 — 状态 + 动态工具 + 动态提示词 + HITL
