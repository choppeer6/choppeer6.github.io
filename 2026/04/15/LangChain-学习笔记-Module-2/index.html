设计模式

  • 主从模式：主 Agent 负责决策，子 Agent 负责专业领域任务
  • 工具封装：子 Agent 通过 @tool 封装，主 Agent 像调用普通工具一样调用它们
  • 职责分离：每个子 Agent 有独立的 system prompt 和工具集

2.4 综合案例：婚礼策划师

案例概述

构建一个多 Agent 婚礼策划系统，包含旅行、场地、音乐三个专业子 Agent，由协调员 Agent 统一管理。

案例要点

  1. 复杂状态流转：先收集信息更新状态，再并行/串行委托子任务
  2. 异构工具集成：MCP 航班、网页搜索、SQL 数据库三种工具协同
  3. 容错设计：MCP 拦截器处理网络波动，工具错误返回给 Agent 自行调整
  4. 递归限制：通过 recursion_limit=40 增加 Agent 最大执行步数

  • 对于复杂数据库，建议在 system prompt 中先让 Agent 探索 schema

总结

Module 2 涵盖了构建复杂 AI Agent 的核心进阶技能：

主题 核心技能
MCP 协议 MultiServerMCPClient、stdio/http 传输、工具/资源/提示词获取
状态管理 AgentState 扩展、Command 更新、ToolRuntime 读写
运行时上下文 context_schema、dataclass 注入非持久化上下文
多 Agent 协作 子 Agent 创建、工具封装、主从协调模式
RAG 文档加载、分块、Embedding、向量存储、相似度搜索
SQL 查询 SQLDatabase、查询工具封装、Agent 自动写 SQL
综合应用 婚礼策划师 — 状态 + MCP + 多 Agent + 搜索 + SQL
