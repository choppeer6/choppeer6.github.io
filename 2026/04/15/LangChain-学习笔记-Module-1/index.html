通过 config 参数指定对话线程 ID：

核心要点

组件 作用
InMemorySaver 内存中的状态检查点，保存对话历史
thread_id 对话会话标识，相同 ID 共享记忆
config 配置对象，用于传递 thread_id 等参数

注意事项

  • InMemorySaver 数据存储在内存中，重启后丢失
  • 生产环境应使用持久化存储（如 Redis、数据库）
  • 不同 thread_id 之间的记忆是隔离的
