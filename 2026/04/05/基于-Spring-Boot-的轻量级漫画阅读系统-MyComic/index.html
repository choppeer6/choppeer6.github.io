基于 Spring Boot 的轻量级漫画阅读系统 MyComic

项目简介

MyComic 是一个基于 Spring Boot 构建的轻量级个人漫画阅读系统，支持本地漫画导入、在线阅读、章节管理等功能。项目采用简洁的单页应用设计，提供流畅的本地阅读体验。

项目地址：https://github.com/choppeer6/mycomic

一、技术栈选型

组件 技术/版本 说明
后端框架 Spring Boot 2.7.18 快速开发，生态完善
数据库 MySQL 8.0 关系型数据存储
ORM MyBatis + Spring Data JPA 混合使用，灵活操作
爬虫解析 Jsoup 1.15.3 HTML 解析与数据采集
分页插件 PageHelper 便捷的分页实现
工具类 Lombok 减少样板代码
前端 原生 HTML/CSS/JS 单页应用风格，轻量简洁

七、扩展方向

  1. OSS 存储：已支持阿里云 OSS 存储图片，减轻服务器压力
  2. 爬虫扩展：基于 Jsoup 实现更多漫画源的爬取
  3. 用户系统：添加用户认证，支持阅读进度同步
  4. 移动端优化：响应式设计或开发配套 App
  5. 阅读体验：添加书签、历史记录、夜间模式等功能

八、总结

MyComic 是一个轻量级但功能完整的漫画阅读系统，展示了：

  • Spring Boot 快速开发 Web 应用
  • MyBatis 灵活的数据访问
  • 本地文件系统与数据库的结合
  • 单页应用的前端架构
  • 图片预加载与懒加载优化

适合作为个人学习项目或小型私有化部署使用。
