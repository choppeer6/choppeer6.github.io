四、P-Code 虚拟机

4.1 什么是 P-Code？

P-Code（Pseudo Code）是一种中间代码，类似于汇编语言，但运行在虚拟机上。这种设计使得编译器与目标机器分离，便于移植。

4.2 P-Code 指令集

指令 格式 功能说明
LIT LIT 0, a 将常数 a 压入栈顶
LOD LOD l, a 将层级差为 l、偏移为 a 的变量值压栈
STO STO l, a 将栈顶值存入层级差为 l、偏移为 a 的变量
CAL CAL l, a 调用层级差为 l 的过程，入口地址 a
INT INT 0, a 开辟 a 个存储单元（数据区扩展）
JMP JMP 0, a 无条件跳转至地址 a
JPC JPC 0, a 栈顶为假（0）则跳转至地址 a
OPR OPR 0, a 执行运算，a 指定具体操作
RED RED 0, 0 读取输入压栈
WRT WRT 0, 0 栈顶值输出并弹出

OPR 运算表：

  • 0: 过程返回
  • 1: 取负
  • 2: 加法
  • 3: 减法
  • 4: 乘法
  • 5: 除法
  • 6: 判断奇数
  • 7: 取模（可选）
  • 8-13: 各种比较运算

七、总结

通过本项目，我们完整实现了一个 PL/0 编译器：

  1. 词法分析：使用正则表达式将源码转为 Token 序列
  2. 语法分析：递归下降法解析程序结构，同时生成中间代码
  3. 代码生成：P-Code 作为机器无关的中间表示
  4. 虚拟机：栈式虚拟机执行 P-Code 指令

这个实现虽然简单，但包含了编译器的核心概念，非常适合作为编译原理的入门实践项目。
